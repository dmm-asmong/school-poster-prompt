# 🖼️ 학교 행사 포스터 프롬프트 빌더

행사명을 쓰고 몇 번만 탭하면 **ChatGPT 같은 이미지 생성 AI에 붙여 넣을 프롬프트**를 만들어 주는 웹앱입니다.
체육대회, 입학식, 졸업식, 학교축제, 캠페인 포스터를 준비하는 선생님을 위해 만들었습니다.

- 무료, 로그인 없음, 광고·추적 없음
- 모든 처리는 브라우저 안에서만 이루어지고 서버로 아무것도 보내지 않습니다
- 이 사이트는 **프롬프트(문장)만** 만듭니다. 이미지는 ChatGPT 등 이미지 AI에서 생성하세요

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 탭 빌더 | 행사명, 학교급, 대상, 용도, 분위기, 화풍, 비율을 칩으로 고르기 |
| 용도별 기본 비율 | 홍보 포스터 4:5, 현수막 21:9, 가정통신문 A4 세로, 발표 자료 16:9 등 자동 설정 |
| 행사 프리셋 (16종) | 행사명에 '체육대회', '입학', 'AI' 같은 단어가 있으면 장면·소품·글자 가이드를 자동 제안 (자유롭게 수정 가능) |
| 화풍 74종 | 장난감·공예, 일러스트, 사진, 회화, 애니·웹툰, 미니멀, 트렌디, 타이포 8개 분류 |
| 자연스러운 한국어 프롬프트 | 마지막은 `AR 4:5`처럼 비율로 끝남, 복사 버튼과 '복사됨' 표시 |
| 수정 요청 칩 | 글자 크게, 색감 밝게, 인물 뒷모습으로, 여백 늘리기 등을 한 번에 덧붙이기 |
| English 프롬프트 | 같은 설정을 영어 프롬프트로 전환 |
| 예시 갤러리 (36개) | 아쉬운 프롬프트 vs 좋은 프롬프트 + 팁, '이 예시로 시작'으로 빌더에 불러오기 |
| 초상권 보호 옵션 | 얼굴이 식별되지 않게 뒷모습·캐릭터로 그리라는 문장을 기본으로 포함 |

## 기술 스택

- Next.js 16 (App Router, 정적 페이지) · React 19 · TypeScript
- Tailwind CSS v4 · Noto Sans KR
- 백엔드, API 키, 데이터베이스 없음

## 로컬 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 프로덕션 빌드
npm run lint
```

## 폴더 구조

```
src/
├─ app/                 # layout, page, 전역 스타일
├─ components/
│  ├─ builder/          # BuilderForm, ChipGroup, PresetPicker, StylePicker, Field
│  ├─ PromptStudio.tsx  # 빌더 상태 + 결과 + 갤러리 연결
│  ├─ PromptPanel.tsx   # 완성 프롬프트, 복사, 수정 칩, 한/영 전환
│  ├─ Gallery.tsx · ExampleCard.tsx
│  └─ Hero · Guide · Header · Footer
├─ data/                # 옵션, 화풍, 행사 프리셋, 수정 칩, 예시 (직접 편집해서 늘릴 수 있어요)
└─ lib/                 # 프롬프트 생성(prompt.ts), 상태/프리셋 적용(builder.ts), 조사 처리, 복사
```

화풍·프리셋·예시를 추가하려면 `src/data/` 안의 파일에 항목을 더하면 됩니다.

## 초상권 안내

실제 학생 사진을 AI에 올리거나 학생 얼굴을 닮게 만들지 마세요. 인물은 뒷모습, 먼 거리, 그림책·캐릭터 화풍으로 표현하는 것을 권장합니다.
